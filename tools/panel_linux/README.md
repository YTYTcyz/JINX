# panel_linux

## 股票悬浮窗

脚本路径：`tools/panel_linux/stock_floating_widget.py`

### 功能

- 输入多个股票代码（逗号、空格都可分隔；A 股六位代码，港股 `HK:00700`/`00700.HK`，美股 `US:AAPL`/`AAPL.US`）
- 悬浮窗置顶显示行情
- 鼠标拖动悬浮窗位置
- 右下角 `⇲` 拖拽缩放
- 控制台用数值输入宽高并应用
- 刷新后按股票行数自动适配高度（1 行即 1 行高度）
- 设置背景色和前景色
- 支持屏幕取色（鼠标点击屏幕任意位置取 RGB）
- 设置字体和字号
- 设置悬浮窗透明度（0.01 ~ 1.00）
- 支持手动刷新和自动刷新
- 自动保存上次配置（代码、位置、大小、颜色、字体、透明度）

### 运行

在项目根目录 `JINX/` 下执行：

```bash
python tools/panel_linux/stock_floating_widget.py
```

行情行会显示市场适配的小数位、实际数据源和数据时间；公共源可能延迟，界面会明确提示。

### 使用说明

1. 在控制台输入股票代码，例如：`600519,000001,HK:00700,US:AAPL`
2. 点击“更新股票列表”
3. 点击“立即刷新”查看实时行情
4. 需要持续刷新时，点击“开始自动刷新”
5. 直接拖动悬浮窗标题栏可移动；拖右下角 `⇲` 可调大小
6. 修改颜色后点击“应用颜色”
7. 使用“屏幕取色”可在全屏截图上点选颜色，RGB 会自动写回
